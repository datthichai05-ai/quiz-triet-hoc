## Task and context management

- At the start of each task, read only sections 0 and 1
  of PROGRESS.md.
- Read other sections only when relevant to the current task.
- Do not automatically execute pending tasks.
- Do not reread the source PDF or large JSON datasets
  unless required by the current task.
- Prefer targeted searches and minimal file reads.
- Update PROGRESS.md briefly after completing a task.
- The user's latest request always determines the task scope.
